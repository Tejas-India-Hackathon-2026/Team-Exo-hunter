Biometric Data Usage Statement

Disha AI Smart Attendance System processes facial images and biometric details solely to register and verify classroom attendance. To ensure compliance with institutional policies, we enforce the following security rules:

1. Biometric Consent Requirements

Student registration is completely optional. Face scanning cannot be initiated until the student explicitly selects the authorization check-box on the registration page.

2. LocalStorage Prototype Sandbox Notice

This version is a client-side prototype. Student metadata (name, roll, email) is stored inside the browser's LocalStorage. Camera feed snapshot images are processed transiently in active memory and **are not saved permanently** to local files or remote hosts.

3. Role-Based Permissions

Access to dashboards, records lists, and unresolved face verify queues is strictly restricted to authenticated Admin and Faculty roles. Session validation checks are run on every page request.

4. Biometric Encryption & Deletion Rights

In production deployment, all facial vector coordinates must be encrypted before database storage. Students reserve the right to review, update, or request complete deletion of their biometric metadata from institutional records according to university rules.

For any questions regarding data storage boundaries or data deletion requests, please contact the IT Administration office at support@dishaai.com.
